# Routeweft

Routeweft is a standalone, local-first LLM routing gateway and control plane.

It is built as its own product and repository. It is not a LiteRouter v2 branch, migration wrapper, or drop-in replacement. Routeweft may use proven routing behavior and visual patterns as references, but it owns its own architecture, storage schema, release process, and operational lifecycle.

The foundation specification is being bootstrapped in a dedicated PR before runtime implementation begins.
